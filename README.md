# CRM Suite - Sistema de Gestión de Relaciones con Clientes

CRM Suite es una aplicación web empresarial moderna y responsiva construida con arquitectura modular en JavaScript, Tailwind CSS y backend Serverless sobre Firebase (Auth + Cloud Firestore).

## Despliegue en Vivo
* **URL de la Aplicación:** https://melisbabosota.github.io/CRM-Suite/index.html
* **Repositorio de Código:** https://github.com/MelisBabosota/CRM-Suite.git

## Tecnologías Utilizadas
* **Frontend:** HTML5, Tailwind CSS, Google Material Symbols, Chart.js.
* **Backend & Persistencia:** Firebase Authentication, Cloud Firestore.
* **Control de Versiones y Hosting:** Git, GitHub, GitHub Pages.

## Módulos Integrados
1. **Autenticación (Login):** Inicio de sesión con credenciales seguras vía Firebase Auth.
2. **Dashboard:** Indicadores clave e ingresos calculados en tiempo real.
3. **Gestión de Clientes:** CRUD completo con filtro de empresas e industrias.
4. **Gestión de Contactos:** Directorio ejecutivo enlazado a clientes.
5. **Oportunidades de Venta:** Embudo de ventas por etapas y montos estimados.
6. **Catálogo de Productos:** Gestión de productos, SKUs, categorías y precios.
7. **Cotizaciones:** Emisión y control de estados (Borrador, Enviada, Aprobada).
8. **Gestión de Tareas:** Tablero de actividades por prioridad y estado.
9. **Usuarios y Roles:** Control de permisos (Administrador, Gerente, Vendedor).
10. **Análisis y Reportes:** Gráficos estadísticos dinámicos (Líneas, Donas, Barras).
